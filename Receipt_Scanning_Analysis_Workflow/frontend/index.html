Project Overview

Receipt Scanning
Analysis Workflow

A production-grade full-stack pipeline that accepts any receipt image or PDF, runs it through OCR, passes raw text to an LLM for structured extraction, persists results to a database, and surfaces real-time analytics — all with a clean API surface.

Processing Pipeline
01
📥
Ingestion
Accept multipart file upload (JPG, PNG, PDF, HEIC). Auto-orient, denoise, and deskew with OpenCV before passing to the OCR engine.
02
👁️
OCR Extraction
Tesseract (or cloud Vision API) extracts all text blocks with positional metadata and per-word confidence scores.
03
🤖
AI Structuring
LLM prompt converts raw OCR text into a validated JSON schema: store, date, mobile, items[], subtotal, tax, total.
04
🗄️
Persistence
Structured document stored in MongoDB with full-text index on store name and item descriptions for O(1) lookup.
05
📊
Analytics
Aggregation pipeline computes monthly totals, category breakdowns, per-mobile summaries, and anomaly flags in real time.
06
🌐
API Surface
FastAPI exposes REST endpoints: POST /upload, GET /receipts, GET /receipts/{mobile}, GET /insights — all OpenAPI documented.

Receipt JSON Schema
"receipt": {
  "id": string,
  "store": string,
  "date": ISO 8601 date,
  "mobile": string | null,
  "payment": "UPI" | "Cash" | "Card" | "Net Banking",
  "category": "Groceries" | "Dining" | "Shopping" | …,
  "items": [{
    "name": string,
    "qty": number,
    "price": number
  }],
  "subtotal": number,
  "tax": number,
  "total": number,
  "notes": string | null,
  "createdAt": ISO 8601 datetime
}
